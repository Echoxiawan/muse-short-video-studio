# 电影感提示词模板（模式 B）

写完先交给用户定稿，再按定稿原文送去生成。人物描述在全片各段逐字复用。单段时间轴按约 10 秒写。对白语言在项目开始时锁定，不要擅自添加某种口音。

字段名可按习惯保留中文；若目标接口更吃英文约束，画幅与禁令可用英文短句加强，例如 `in exactly 16:9 aspect ratio`。

## 通用模板

```
[时长/画幅] [一句话场景]
in exactly [16:9 | 9:16] aspect ratio
人物：年龄 / 性别 / 外貌特征 / 服装 / 发型（精确到颜色与款式）
场景：地点 / 时间 / 光线 / 氛围
剧情/节拍（带时间轴）：
  0-3秒：...
  3-7秒：...
  7-10秒：...
镜头语言：机位 / 运镜 / 景别 / 手持或稳定 / 禁止的运镜
声音：环境音 / 拟音 / 台词（注明语气与口型）
对白语言：[项目已锁定的语言；无对白则删本行]
参考图说明：（只参考人物/服装/场景中的哪部分；文件名须为 ASCII。无参考图则删本行）
限制：不要……（逐条列出禁止项：穿模、变形、磨皮、误入镜、屏幕文字、水印等）
```

## 变体：POV 生活流

在模板最前面单独成段写死视角约束，不要把「本人不要入镜」轻轻夹在长句里：

```
全程严格第一人称：镜头就是〔同伴〕的眼睛，本人绝不入镜，只允许手或前臂偶尔出现在画面边缘。
in exactly [16:9 | 9:16] aspect ratio
人物：（被拍摄者的逐字锁定描述）
场景：...
剧情/节拍（带时间轴）：
  0-3秒：...
镜头语言：手持、视高与行走晃动要克制；禁止切到第三人称、禁止出现拍摄者的脸或肩膀大面积入镜
声音：...
限制：不要出现拍摄者的脸或躯干；不要切到旁观机位；不要……
```

## 变体：口播 talking-head

```
[时长/画幅] 口播：人物正对镜头，视线看镜头。非自拍，画面中不出现相机或手机。
in exactly [16:9 | 9:16] aspect ratio
人物：...
场景：...
剧情/节拍（带时间轴）：
  0-2秒：看镜头，准备开口
  2-8秒：说出台词
  8-10秒：收在一个表情或动作上
镜头语言：稳定中近景，轻微推或不推；禁止晃成自拍、禁止出现提词器或字幕板
声音：她/他说：「……」。语气……。声音与画面同步，口型与台词对齐，无文字叠加。
对白语言：...
限制：不要磨皮网红脸；不要屏幕字幕；不要……
```

## 变体：多段长片（>10 秒）

每段一个独立提示词。段首声明接续关系，每段只写本段 2–3 个镜头，不写全片。生成时用上一段的续接快照 id。

```
本段为〔总时长〕短片的第 N 段（X-Y 秒），延续上一段的同一人物/场景/光线/质感，人物服装发型面容严格保持一致。
in exactly [16:9 | 9:16] aspect ratio
人物：（与第 1 段逐字相同的描述）
场景：...
剧情/节拍（带时间轴，只写本段的约 10 秒）：
  0-4秒：...
  4-10秒：...
镜头语言：...
声音：...
限制：不要面部漂移；不要服装跳变；不要……
```

## 写作备忘

- 限制清单宁多勿少；上一轮失败过的现象要写进这一轮。
- 方向词写死：走出 / 走进、左转 / 右转、靠近 / 远离。
- 颜色写绝对值并排除偏向。
- 关键约束单独成段。
- 不需要锁特定真人时，不必强行附加参考图。
