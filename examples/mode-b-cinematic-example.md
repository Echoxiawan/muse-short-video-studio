# 模式 B 示例：雨夜面摊（虚构短片，约 30 秒）

这是一份可按本包流程跑通的虚构例子，用来演示：带时间轴的提示词、人物描述逐字复用、快照顺序接续、拼接与抽帧。不是任何已有电影或广告的再现，也不涉及真实人物。

## 项目锁定

- 画幅：16:9
- 语言：普通话，自然口语，不另加地域口音
- 片长：约 30 秒，拆成 3 段，每段约 10 秒、2–3 个镜头
- 连续性：后一段使用前一段的续接快照（如 `resume_from_snapshot_id`），顺序生成，不并行
- 不承诺锁脸；本例只有两个核心人物，靠逐字复用提高延续概率

## 人物锁定（三段逐字相同）

- 林渡，约 28 岁亚洲男性外卖骑手：偏瘦，额头贴着被雨打湿的短黑发，橄榄色雨衣有一条细反光条，左肘挂着哑光黑头盔，深色长裤，湿透的帆布鞋。
- 周阿姨，约 60 岁亚洲女性面摊老板：花白发髻，褪色靛蓝围裙罩在锈棕色毛衣外，蒸汽熏得两颊微红，手上有面汤色的薄茧。

## 段 1（0–10 秒）提示词定稿

```
本段为 30 秒短片的第 1 段（0-10 秒）。
in exactly 16:9 aspect ratio
人物：林渡，约 28 岁亚洲男性外卖骑手：偏瘦，额头贴着被雨打湿的短黑发，橄榄色雨衣有一条细反光条，左肘挂着哑光黑头盔，深色长裤，湿透的帆布鞋。周阿姨，约 60 岁亚洲女性面摊老板：花白发髻，褪色靛蓝围裙罩在锈棕色毛衣外，蒸汽熏得两颊微红，手上有面汤色的薄茧。
场景：南方老城区雨夜巷口，一盏暖黄灯笼照着铁皮面摊，地面有积水倒影，蒸汽从锅里升起，远处有稀疏自行车铃。
剧情/节拍（带时间轴）：
  0-3秒：骑手从巷口踏入积水，停在摊前，先把头盔从肘上放下，再掀开雨衣帽子。
  3-7秒：他低头看着锅面，雨水从发梢滴进碗边。
  7-10秒：周阿姨把一碗热面推向他，蒸汽挡了一下两人的视线。
镜头语言：35mm 稳定中景起，缓慢推向半身；禁止甩镜，禁止切到白天。
声音：雨打铁皮棚、锅气、远处很轻的车铃。本段无对白。
限制：不要出现字幕或招牌乱码；不要磨皮；不要把雨夜拍成晴天；不要让第三个人走进镜头前；不要面部漂移；不要服装跳变。
```

记下本段返回的快照 id，例如 `snap_seg1`（此处为占位，以实际返回值为准）。

## 段 2（10–20 秒）提示词定稿

```
本段为 30 秒短片的第 2 段（10-20 秒），延续上一段的同一人物/场景/光线/质感，人物服装发型面容严格保持一致。
in exactly 16:9 aspect ratio
人物：林渡，约 28 岁亚洲男性外卖骑手：偏瘦，额头贴着被雨打湿的短黑发，橄榄色雨衣有一条细反光条，左肘挂着哑光黑头盔，深色长裤，湿透的帆布鞋。周阿姨，约 60 岁亚洲女性面摊老板：花白发髻，褪色靛蓝围裙罩在锈棕色毛衣外，蒸汽熏得两颊微红，手上有面汤色的薄茧。
场景：同一雨夜面摊，暖黄灯笼，铁皮棚，地面积水倒影，碗面热气仍在。
剧情/节拍（带时间轴）：
  0-4秒：林渡坐下，先把湿头盔放在身边凳上，再捧起碗。
  4-10秒：周阿姨擦了擦手，看他吃了一口，轻轻说：「路还远不远。」林渡咀嚼完才答：「再两单。」口型与台词对齐，无文字叠加。
镜头语言：过肩到近景，稳定，轻推到两人半身；禁止切走摊位，禁止自拍机位。
声音：雨声略小，面汤轻轻的吸气声。对白语言：普通话，自然口语，不刻意表演。
限制：不要面部漂移；不要服装跳变；不要屏幕字幕；不要第三人入镜；不要把对话变成群戏。
```

生成时传入 `resume_from_snapshot_id=snap_seg1`，顺序等待完成后再开第 3 段。

## 段 3（20–30 秒）提示词定稿

```
本段为 30 秒短片的第 3 段（20-30 秒），延续上一段的同一人物/场景/光线/质感，人物服装发型面容严格保持一致。
in exactly 16:9 aspect ratio
人物：林渡，约 28 岁亚洲男性外卖骑手：偏瘦，额头贴着被雨打湿的短黑发，橄榄色雨衣有一条细反光条，左肘挂着哑光黑头盔，深色长裤，湿透的帆布鞋。周阿姨，约 60 岁亚洲女性面摊老板：花白发髻，褪色靛蓝围裙罩在锈棕色毛衣外，蒸汽熏得两颊微红，手上有面汤色的薄茧。
场景：同一巷口面摊。雨势收小，积水仍在，灯笼还是暖黄，不要变成日出。
剧情/节拍（带时间轴）：
  0-4秒：林渡把钱按在板台上，先戴上头盔，再拉上雨衣帽子。
  4-10秒：他推车走进巷影，周阿姨在灯笼下收回空碗；镜头不跟出巷口太远，收在摊位暖光里。
镜头语言：从半身缓拉成中全景，稳定；禁止跳接到其他街区，禁止变成白天。
声音：雨变细，车轮碾过积水。本段无对白。
限制：不要面部漂移；不要服装跳变；不要晴天；不要字幕；不要新的人物走到镜头前。
```

传入上一段快照 id，顺序生成。

## 拼接与抽帧

```bash
# 先确认每段宽高一致，再拼接
bash scripts/stitch_clips.sh -a 16:9 -o rain-stall-full.mp4 \
  rain-stall-seg1.mp4 rain-stall-seg2.mp4 rain-stall-seg3.mp4

python3 scripts/extract_frames.py rain-stall-seg1.mp4 --junction rain-stall-seg1-ends
python3 scripts/extract_frames.py rain-stall-seg2.mp4 --junction rain-stall-seg2-ends
python3 scripts/extract_frames.py rain-stall-seg3.mp4 --junction rain-stall-seg3-ends
python3 scripts/extract_frames.py rain-stall-full.mp4 6 rain-stall-full-qc
```

把 seg1 尾帧与 seg2 首帧、seg2 尾帧与 seg3 首帧并排看：查换脸、换装、摊位是否还是同一个。第 2 段对白、口音和口型交给用户终验。有意设计的「雨势收小」不要写成连续性错误，但须在交付里注明。
