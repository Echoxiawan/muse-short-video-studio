# 模式 A：前期策划

用于构思、脚本、分镜、美术和声音方向。产出策划包，可以在分镜后停止，不必立刻生成。本阶段是策划，不是出片：不擅自发起付费网络请求或第三方生成调用。

填写产出时使用 [templates/creative-package.md](../templates/creative-package.md)。若随后走模式 B 或 C，把过密的分镜收成「每段约 10 秒、每段 2–3 个镜头」，并遵守 [SKILL.md](../SKILL.md) 的共同硬规则。

## 开始前先锁定

未确认之前不要往下写脚本或分镜。问清并写进策划包首页：

- 目标与媒介（广告、叙事短片、产品演示、片头等）
- 大致片长
- 画幅（16:9 / 9:16 / 其他）
- 成片语言
- 受众与平台
- 限制（品牌禁区、必须出现的信息、能否出镜真人、预算与是否允许付费生成）

用户没说的参数要问，不要编造。

## 两条管线，按需选择

满足以下至少两条，走**快速管线**：场景不超过 2 个、无稳定角色需求、用户要求尽快、brief 已经完整。否则走**标准管线**。快速管线执行中若修改点超过三处、用户反复加需求，或要新增角色/场景，则降级回标准管线，已完成部分保留。

### 标准管线

流程按需裁剪；导演审核每个创意阶段最多改两轮，两轮后必须带条件通过或退回重做该阶段。

1. **需求**：目标、时长、画幅、媒介、受众、限制。若用户提供参考视频，只提炼镜头语言、叙事、色彩、声音等方法，写成技法摘要交给后续阶段；不搬运受版权保护的画面、商标或角色造型。
2. **内容**：故事或卖点、结构、节拍、角色身份（如有）。
3. **视觉开发**：美术方向、色彩、场景空间、人物造型。情绪不要只写「伤感/温暖」，要写造成这种观感的光线与材质原因（例如「阴天窗光 + 桌面湿反光」，而不是「悲伤的蓝」）。参考图按资产编号引用原文件，不要用文字转述走样。
4. **条件性风格定样**（需要且用户已同意生成费用时才做）：用用户指定的生图方式出情绪板或角色概念图，请用户看图锁定。用户未同意付费生成则跳过，用文字方向代替，并在策划包里标明「未定样」。
5. **脚本**：文学剧本。字幕/对白与画面提示词解耦——字幕作为后期烧录说明，因为模型文字渲染不可控。
6. **声音方向**：音乐、音效、旁白基调与静默位置。本阶段只写方向，不代为生成音轨。
7. **分镜**：镜头列表、运镜、景别、时长、声音提示。若接下去走约 10 秒一段的出片，把过密分镜合并或拆段。
8. **组装策划包**：按 [templates/creative-package.md](../templates/creative-package.md) 汇总，交给用户确认。
9. **可选：模型编译**：仅在用户指定了目标模型之后，把策划包编译成该模型的「调用指令文本」。编译器只做格式转换，不改写创意判断，不发起网络请求。没有指定模型就跳过，不要把任何一家模型写成默认编译目标。

### 快速管线

1. 需求锁定（同上，不可省略）。
2. 把内容、视觉和脚本合成一稿（故事/卖点、美术方向、镜头与对白一起交）。
3. 声音方向 + 精简分镜 + 组装策划包，一次终审。

## 角色按需加载，不要一次全盘展开

导演是审核人，不替代其他角色写专业内容。每个阶段只启用当时需要的角色。

| 角色 | 何时启用 | 主要产出 |
|---|---|---|
| 导演 | 需求锁定与每阶段审核 | 项目方向、约束、通过/修改/退回 |
| 编剧 | 内容与脚本 | 故事线、logline、场次、对白、情绪曲线 |
| 美术指导 | 视觉开发 | 色彩、风格、场景空间、人物造型 |
| 摄影指导 | 脚本与分镜 | 景别、运镜、镜头、光线 |
| 特效指导 | 需要非常规画面或转场时 | 材质、转场、合成层级说明 |
| 声音指导 | 声音方向 | 配乐风格、音效、旁白、静默 |

策划状态用一份结构化记录在阶段之间传递（目标、已锁定项、各阶段产出、待确认项）。每条创意产出应能追溯到是哪个角色、第几稿。

## 编剧方法（精要）

按时长和类型选结构，可混合，不要为短片硬套完整英雄之旅：

- **三段式**：建立（约 25%）→ 冲突（约 50%）→ 收束（约 25%）
- **蒙太奇**：以主题或产品串联，无强因果，信息量递增后落地
- **问题—解决**：问题 → 放大 → 介入 → 解决 → 行动号召
- **反转**：铺垫与误导 → 翻转预期 → 点题
- **情绪递进**：同一情感层层加强，结尾共鸣

对白宜短。能用动作或表情代替的句子就不要直说心情。需要留白时在脚本里标出静默秒数。广告腔（最好、第一、领先）默认不用，除非用户要这种语气。多角色时，不看名字也应能从口吻分辨说话人。

Logline 可用：「当〔谁〕面对〔障碍〕，必须〔行动〕，否则〔代价〕。」产品片可改成「〔用户〕被〔问题〕困扰，直到〔产品〕用〔功能〕改变局面。」

## 摄影与美术方法（精要）

景别：远景、全景、中景、近景、特写、大特写。运镜：固定、推、拉、摇、移、跟、升/降、环绕；写进分镜时要用动词写清楚起止，避免只写「电影感运镜」。焦段用用途描述（如「35mm 靠近但仍看见环境」「85mm 压缩背景、突出表情」），不要堆器材口号。

光线先写来源与方向（窗、实用灯、阴天、单一硬光），再写想要的情绪。构图写主体位置、前景遮挡、是否对称、是否留白。

风格方向由用户或策划决定，不要默认某一种片厂或某一种网红滤镜。

## 声音方法（精要）

先定「要不要音乐、要不要旁白」。静默是设计，不是漏做。旁白覆盖不宜占满全片；高潮段可以交给画面和音效。对白、旁白、字幕三者不要在策划里互相抢同一句话。

## 可选编译器（不是默认出片步骤）

仅当用户已经指定目标模型，并要求把策划包写成可粘贴的调用指令时使用。规则：

- 只读取策划包字段，不修改上游创意文本的原意；翻译成模型所需语言或字段格式时，保留原文溯源。
- 画幅、时长、参考文件编号必须写进指令；缺关键段时标出质量警告，缺得太多则暂停等用户确认。
- 输出是指令文本（提示词、参考引用、时长与比例说明），不是一次实际调用。
- 不要把某一家云厂商、某一条 CLI、某一个模型 ID 写成默认目标。

若用户指定需要强锁脸的下游模型，按该模型的提示词格式编译，不要硬套模式 B 或模式 C 的模板。锁脸优先使用用户提供的原图作参考，不要先经中间生图模型转绘再用。

## 本阶段停止线

用户确认策划包后，问是否进入模式 B、模式 C，或到此结束。未得到生成授权前，不要调用任何生成后端。
