# 验收清单

没抽帧、没看过、没听过的内容，不说「没问题」。观察与推断分开写：看得到的写成事实，得不到的标「待确认」或「待用户终验」。

配套脚本：[scripts/extract_frames.py](../scripts/extract_frames.py)、[scripts/stitch_clips.sh](../scripts/stitch_clips.sh)。交付文书模板：[templates/delivery-notes.md](../templates/delivery-notes.md)。

## 1. 技术规格

对每一段以及最终成片运行 `ffprobe`：

```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream=width,height,r_frame_rate,codec_name,duration \
  -of default=noprint_wrappers=1 FILE

ffprobe -v error -show_entries stream=codec_type,codec_name \
  -of default=noprint_wrappers=1 FILE
```

- [ ] 画幅与项目锁定值一致（16:9、9:16 等），没有把横竖版素材混进同一成片
- [ ] 各段宽高一致；不一致则已先规范再拼接，没有直接硬拼
- [ ] 时长符合「每段约 10 秒」的规划；长片总时长接近场次数 × 单场时长
- [ ] 成片同时具有预期的视频轨；若应当有声音，确认存在音频轨
- [ ] 文件名是 ASCII

规范默认（仅在需要重编码时）：16:9 → 1280×720，9:16 → 720×1280，24fps。

## 2. 抽帧怎么抽

```bash
# 单段均匀抽 4 帧
python3 scripts/extract_frames.py seg1.mp4 4 seg1-qc

# 首帧、中点、尾帧（看一场内部和场次交界）
python3 scripts/extract_frames.py seg1.mp4 --junction seg1-ends
python3 scripts/extract_frames.py seg2.mp4 --junction seg2-ends
```

建议最少覆盖：

- 每段至少 3 帧（偏前、中间、偏后）
- 每个段交界：上一段尾帧与下一段首帧并排对比
- 每个关键节拍点（提示词里写过的动作或台词落点）再补 1 帧

## 3. 画面与提示词对照

- [ ] 人物年龄、发型、服装、识别特征是否吃进提示词或角色表
- [ ] 场景地点、时间、光线是否大致正确
- [ ] 时间轴上的节拍是否出现（不要把「压缩了但还在」和「完全没发生」写成一回事）
- [ ] 限制清单里禁止的内容是否出现（误入镜、磨皮网红脸、文字水印、穿模等）
- [ ] 动作因果是否成立（门是否先打开，方向是走出还是走进）
- [ ] 画风、色板是否与锁定方向一致（不要把有意的风格变化判成错误）

写结论时分三栏：吃进项 / 偏差项 / 原因推测。

## 4. 连续性（按模式检查，不要混用标准）

### 模式 B（快照顺序接续）

- [ ] 后一段确实使用了前一段的续接快照，没有并行生成后硬接
- [ ] 人物描述在各段提示词中逐字相同
- [ ] 交界处是否换脸、换装、场景断裂、光线突变（有意的时间推进要在交付里注明）
- [ ] 群戏是否出现全员替换；若出现，如实记录，不要写成「快照已经锁脸」

### 模式 C（Match Cut）

- [ ] 第 N 场尾帧和第 N+1 场首帧在素材表里指向**同一个文件**
- [ ] 生成结果的交界仍然接近该关键帧，没有各自漂成两张无关的画
- [ ] 角色与设定表对照仍然 on-model
- [ ] 所有关键帧和设定表都是锁定画幅，没有混用比例

## 5. 声音

执行者常常听不见成片音频，必须把下列事项交给用户终验：

- [ ] 已用 `ffprobe` 确认原片有无音轨；有则说明保留还是压低
- [ ] 对白或旁白是否说对、语言和口音是否符合项目锁定
- [ ] 口型是否大致对齐（口播和照片说话尤其重要）
- [ ] 环境声、配乐是否合适，有无突然切断或盖过对白
- [ ] 旁白是否过满（动画短片建议不要占满全部时长）

在交付说明里单独列出「音频待验」，不要用「应该没问题」带过。

## 6. 发布判断

只根据已经检查过的证据下判断：

| 结论 | 含义 |
|---|---|
| 可交付 | 规格正确，抽帧未见硬伤，待验项已列出 |
| 后期可修 | 问题能靠剪辑、音量、微调或烧字幕解决，不必重生成 |
| 重跑某段 | 问题集中在某一时间范围，回到该模式只重做这一段 |
| 不通过 | 画幅错误、动作不成立、身份完全漂掉且用户要求锁定、或未获授权的人脸内容 |

重跑某段时：

- 模式 B：用该段前一段的快照重新顺序生成
- 模式 C：先检查 mega prompt 和首尾帧文件，不要盲目重试超过 2–3 次
- 模式 D：未经用户同意，不对可能扣费的任务自动重提

定位问题时尽量写到时间范围，例如「以 00:03.2 附近为参考，重做 00:04.2–00:05.8 所在段」。

## 7. 交付前最后一眼

- [ ] 成片路径、画幅、时长、场次结构已写清
- [ ] 吃进了什么、偏了什么已写清
- [ ] 密钥和完整令牌没有出现在说明里
- [ ] 若只完成了策划，已明确到此为止，没有把策划包写成已生成的成片
- [ ] 失败的尝试没有写成成功案例；可记录有效提示词和失败原因供下次复用
